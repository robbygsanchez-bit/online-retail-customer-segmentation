# online-retail-customer-segmentation
Segmentation project for AI &amp; Machine Learning Capstone
# Dataset

This project uses the **Online Retail Dataset** from the UCI Machine Learning Repository.

The dataset contains transactional records from a UK-based online retailer between December 2010 and December 2011.

Dataset source:

UCI Machine Learning Repository — Online Retail Dataset

The original dataset is not included in this repository. It can be downloaded from the UCI Machine Learning Repository and loaded into the provided Jupyter/Google Colab notebook.

The notebook expects the dataset file to be named:

`Online Retail.xlsx`
